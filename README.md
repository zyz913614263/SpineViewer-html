# SpineViewer

在浏览器里打开 Spine 骨骼，播放动画，并导出当前画面或 GIF。

支持 Spine 3.3–3.8 与 4.0、4.1、4.2、4.3 导出的 JSON。3.3 到 3.7 用 3.7 播放器打开，3.8 用 3.8 播放器。把同一套文件放在一起，拖进页面，或用「打开文件」「打开文件夹」。程序会按同名、同目录自动配上 JSON（或 skel）、atlas 和贴图，例如 `hero.json`、`hero.atlas`、`hero.png`。一个文件夹里有多套骨骼时，右侧可以切换。二进制 `.skel` 从 3.8 起会按文件头里的版本选择对应播放器；3.7 及更早请导出 JSON。

播放器来自 Esoteric Software 的 Spine Runtimes，许可见 `vendor/SPINE-RUNTIMES-LICENSE.txt`。直接双击 `index.html` 即可使用，文件都在本地读取，不会上传。

- 空格播放或暂停，左右方向键逐帧。
- 皮肤页可叠加 default 以外的皮肤。插槽前的勾选用来隐藏部件。
- 「导出 PNG」保存当前画面。「导出 GIF」按右侧帧率采样整段动画，最长边约 480 像素。
- 棋盘背景导出的 PNG 是透明的。GIF 会带上当前背景。

3.2 及更早的文件不在支持范围内。
